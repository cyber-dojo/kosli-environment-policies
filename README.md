# kosli-environment-policies

Github Action pipeline yaml to create [Kosli](https://docs.kosli.com/) compliance policies
and attach them to the cyber-dojo [aws-beta](https://app.kosli.com/cyber-dojo/environments/aws-beta/snapshots/) 
and [aws-prod](https://app.kosli.com/cyber-dojo/environments/aws-prod/snapshots/) Kosli AWS Environments.
